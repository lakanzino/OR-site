# نسخهٔ ۰٫۲۱٫۱ — پیوند آبی، کادر عنوان سرمه‌ای، جدول کامل

**تاریخ:** ۲۰۲۶-۱۰-۲۸ · **قالب فرزند:** `lax-theme-child` 0.21.1 · **افزونه:** `hamyar-sentinel-agent` 1.0.0 (بدون تغییر)

نسخهٔ ظاهریِ مقاله؛ هیچ تغییری در ساختار، محتوا یا پیشخوان ندارد.

| درخواست | نتیجه |
|---|---|
| لینک‌های زیرخط‌دار آبی | `#1d4ed8` (کنتراست ≈ ۶ روی سفید) · هاور `#1e40af` · بازدیدشده `#4338ca`؛ زیرخط ملایم حفظ شد |
| کادر عنوان با سایهٔ عمیق، سرمه‌ای، متن سفید | H2 با پس‌زمینهٔ سرمه‌ای، متن سفید، نوار کناری آبی و سایهٔ دولایه |
| جدول کامل در موبایل و دسکتاپ، بدون اسکرول افقی | `table-layout: fixed` + شکستن واژه‌های بلند + فونت ۰٫۸rem در موبایل؛ اسکرول برداشته شد |
| زیرنویس تصویر ریزتر و طوسی تیره | ۰٫۷۸rem · `#374151` · کادر خاکستری روشن بدون سایه |
| مرتب‌شدن پایان سطرها | `text-align: justify` + `text-justify: inter-word` برای پاراگراف و فهرست؛ سلول‌های جدول مستثنا |

## یک نکتهٔ فنی

«کشیدن حروف» (kashida) در CSS امروز مرورگرها وجود ندارد؛ `text-justify: kashida` فقط در IE/Edge قدیمی بود. کاری که مرورگر انجام می‌دهد کشش فاصلهٔ بین کلمات است — همان چیزی که این نسخه فعال می‌کند و نتیجه‌اش پایان سطرهای هم‌تراز است.
