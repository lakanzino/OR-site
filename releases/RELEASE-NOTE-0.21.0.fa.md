# نسخهٔ ۰٫۲۱٫۰ — بازگشت مقاله به ۰٫۱۴ و پاک‌سازی تکرارها

**تاریخ:** ۲۰۲۶-۱۰-۲۸ · **قالب فرزند:** `lax-theme-child` 0.21.0 · **افزونه:** `hamyar-sentinel-agent` 1.0.0 (بدون تغییر)

## چرا

هر مقاله دو فهرست منابع، دو پرسش متداول و دو سلب مسئولیت داشت؛ فهرست مطالب به آخر صفحه افتاده بود و «سؤال‌هایی که باید از پزشک پرسید» در راهنماهای بی‌جراحی هم چاپ می‌شد. علت: سه تزریق مستقل روی `the_content` (نسخه‌های ۰٫۱۵، ۰٫۱۸ و ۰٫۱۹) که هر کدام فرض می‌کردند تنها تزریق‌کننده‌اند.

## چه شد

| مورد | نتیجه |
|---|---|
| ظاهر مقاله | `single.php` عیناً از تگ `child-v0.14.0` بازگردانده شد؛ بلوک‌های CSS ۰٫۱۵–۰٫۲۰ مخصوص مقاله حذف شد (۳۷۴۰ → ۲۹۳۹ خط) |
| منابع | دیگر تزریق نمی‌شوند؛ فهرست خودِ مقاله یک‌بار و در همان جای نوشته‌شده می‌ماند |
| پرسش‌های متداول | آکاردئون تزریقی خاموش؛ FAQ خودِ متن دست‌نخورده |
| «سؤال‌هایی که باید پرسید» | تزریق ۰٫۱۵ خاموش شد؛ در هیچ مقاله‌ای چاپ نمی‌شود |
| سلب مسئولیت | دقیقاً یکی: باکس زرد کوچک، **پیش از** فهرست منابع؛ همهٔ نسخه‌های متنی دیگر پاک می‌شوند |
| جدول مقاله | `.hj-table-scroll` — دسکتاپ وسط‌چین با عرض طبیعی، موبایل اسکرول افقی |

| صفحهٔ اصلی | جملهٔ حقوقی زیر کپی‌رایت و جملهٔ «بدون جاوااسکریپت هم می‌شود…» حذف شد |

## چه چیزی عوض نشد

گیت انتشار، فهرست سفید منابع، سنتینل، اسکیما، آپدیتر گیت‌هاب و برچسب منوها همه سر جایشان‌اند — این‌ها پیشخوان یا سرور هستند و ظاهر مقاله را دست نمی‌زنند.

## نصب و بررسی

1. پیشخوان → «بروزرسانی گیت‌هاب» → **بررسی دوبارهٔ گیت‌هاب** → ۰٫۲۱٫۰ → بروزرسانی.
2. یک مقاله را باز کن: منابع باید یک‌بار و آخر صفحه باشد، سلب مسئولیت یک باکس زرد کوچک پیش از منابع.
3. صفحهٔ اصلی: زیر کپی‌رایت فقط خط حقوق نشر؛ بالای فوتر یک خط اورژانس.

> اگر متنی با لحن «هوش مصنوعی» داخل خودِ مقاله دیدی، آن متن در پایگاه‌داده است نه در قالب؛ نمونه را بفرست تا حذف/بازنویسی شود (`T-55`).
