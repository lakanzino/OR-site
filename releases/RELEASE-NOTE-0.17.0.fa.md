- **قاعده:** ۳ دامنهٔ متفاوت معتبر + دست‌کم ۱ منبع ردهٔ ۱ (WHO / NIH-MedlinePlus / CDC / Mayo / UpToDate / Cochrane / NHS / NICE / MSD / وزارت بهداشت / دانشگاه‌های `ac.ir`).

- **باکس کنار ویرایشگر** می‌نویسد «منابع معتبر: ۲ از ۳ — medlineplus.gov، www.sages.org» و اگر ردهٔ ۱ نباشد همان‌جا می‌گوید.
- گیت فقط **انتشار تازه** را می‌بندد؛ مقالهٔ زنده هرگز به پیش‌نویس برنمی‌گردد؛ عبور با تیک مدیر سایت.
