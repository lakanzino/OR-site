# نسخهٔ ۰٫۲۰٫۲ — یادداشت انتشار

**تاریخ:** ۲۰۲۶-۱۰-۲۸ (۶ آبان ۱۴۰۵) · **قالب فرزند:** `lax-theme-child` 0.20.2 · **افزونه:** `hamyar-sentinel-agent` 1.0.0 (بدون تغییر)

نسخهٔ وصله‌ای: هدر و اسکریپت‌های قالب والد دست‌نخورده‌اند؛ دو فایل تازه و یک بلوک CSS اضافه شده است.

## در این بسته

| فایل | توضیح |
|---|---|
| `lax-theme-child-0.20.2.zip` | قالب فرزند — از «نمایش → پوسته‌ها → افزودن → بارگذاری» یا از «بروزرسانی گیت‌هاب» |
| `orsite-docs-0.20.2.zip` | اسناد، گزارش‌ها و پیش‌نمایش‌ها |

## ۱) منوها در پیشخوان

- موقعیت‌های منو **از قبل وجود داشتند**: `primary` (سربرگ) و `footer` (پابرگ). نامشان انگلیسی و گنگ بود.
- اکنون در «نمایش → فهرست‌ها» می‌بینید:
  - **منوی اصلی سربرگ (دسکتاپ و موبایل)**
  - **منوی پابرگ**
- همان فهرست‌ها سر جایشان می‌مانند؛ فقط برچسب عوض شده است.
- یک یادداشت کوتاه هم بالای همان صفحه توضیح می‌دهد که **منوی موبایل همان منوی سربرگ است** (زیر ۷۶۸px داخل دکمهٔ همبرگری جمع می‌شود)، پس فهرست دوم لازم نیست.
- اگر جایی از مستندات قدیمی نام `menu-1` را دیده‌اید: با فیلتر `hj_nav_menu_location_alias` همان فهرست روی `primary` نمایش داده می‌شود.

## ۲) نوار اورژانس بالای صفحه

- یک خط باریک زیر هدر: «علائم خطر جدی؟ …» + دکمهٔ **۱۱۵ · تماس با اورژانس** (`tel:115`).
- بدون جاوااسکریپت، بدون تصویر و بدون فونت تازه؛ ارتفاع ثابت → **بدون CLS**.
- در چاپ، فید و صفحهٔ ۴۰۴ نمایش داده نمی‌شود. خاموش‌کردن: فیلتر `hj_emergency_bar_enabled`.

## ۳) چه چیزی عمداً انجام نشد

| پیشنهاد | دلیل |
|---|---|
| ساخت `header.php` تازه | والد لوگو، skip-link، منوی سربرگ، دکمه/پنل جستجو و اسکریپت `main.js` را دارد؛ جایگزینی یعنی از دست رفتن همهٔ این‌ها |
| ثبت `menu-1` و `mobile-menu` | هیچ تمپلیتی آن‌ها را چاپ نمی‌کند؛ چک‌باکس بی‌اثر، سردبیر را گمراه می‌کند |
| کشوی Off-Canvas + `hamyar-menu.js` | همان رفتار در والد هست؛ دو کنترل روی یک دکمه + قفل اسکرول در Escape |
| جستجوی بازشونده | `search-toggle` و `#header-search` والد |
| پیش‌بارگذاری فونت با `/fonts/…` | مسیر وجود ندارد (فونت در `assets/fonts/fa/`)؛ والد از قبل preload می‌کند → ۴۰۴ |
| بَج «پزشکان ناظر» → `/advisory-board/` | ADR-020 و نبود چنین صفحه‌ای |

جزئیات: `docs/DECISIONS.md` → ADR-029.

## نصب و بررسی

1. از پیشخوان «بروزرسانی گیت‌هاب» → نسخهٔ ۰٫۲۰٫۲ → به‌روزرسانی (یا zip را دستی نصب کنید).
2. «نمایش → فهرست‌ها»: برچسب‌های فارسی و یادداشت را ببینید و فهرست دلخواه را به «منوی اصلی سربرگ» وصل کنید.
3. یک صفحهٔ مقاله را در موبایل باز کنید: نوار ۱۱۵ بالای صفحه و منوی همبرگری والد باید کار کنند.
