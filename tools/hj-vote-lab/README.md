# HJ Vote Lab ۰٫۲٫۰ — ابزار آزمایش رأی و گزارش

ابزار مستقل برای درج نظرهای آزمایشی فقط روی پروفایل‌های دارای متای `_hj_demo_doctor` و دریافت JSON تجمیعی. برای کار به افزونه اصلی همیار پزشک‌ها متکی است، اما فایل‌های آن یا قالب را تغییر نمی‌دهد و جدول تازه ایجاد نمی‌کند. نصب و اجرای آن با مدیر است.

**تغییر ساختار:** اگر جدول رأی ستون متن قابل‌شناسایی نداشته باشد، با تأیید مدیر و هنگام نخستین درج معتبر، ستون nullable به نام `comment` به جدول رأی موجود افزوده می‌شود. این `ALTER TABLE` دائمی، خارج از تراکنش درج و احتمالاً دارای قفل کوتاه یا طولانی جدول است. برای ردیف‌های قبلی مقدار آن `NULL` است. اگر درج بعداً ناموفق شود، ستون همچنان باقی می‌ماند. غیرفعال‌کردن/حذف افزونه ستون یا رأی‌ها را پاک نمی‌کند. ابتدا پشتیبان فایل و دیتابیس قابل‌بازیابی تهیه کنید. سایر hookها، triggerها و کش خارج از کنترل افزونه‌اند.

- پیشخوان ← ابزارها ← آزمایش رأی نمونه؛ جراح نمونه و ۱ تا ۱۰ خط `5 | متن` یا CSV کوچک UTF-8 دو ستون `rating,comment` (header اختیاری) انتخاب کنید. فایل انتخاب‌شده جایگزین متن کادر می‌شود. ارقام فارسی و انگلیسی امتیاز مجازند.
- وضعیت پیش‌فرض این نسخه «تأییدشده» است تا تست نمایش ساده باشد؛ این رأی‌ها ممکن است در سایت عمومی و آمار ظاهر شوند. حالت pending قابل انتخاب است. کش و تنظیمات مستقل امتیاز/override ممکن است نتیجه را تغییر دهند؛ افزونه کش یا متاهای امتیاز را تغییر نمی‌دهد.
- لینک «دانلود گزارش» برای هر جراح شامل metadata و آمار تجمیعی آرای همان جراح، نتیجه bridge و تعداد نظرهای تابع پروفایل است، نه متن نظر، IP، شناسه رأی‌دهندگان یا نام پزشک. در نبود ستون متن، مقدار نشانگر شمار آزمایشی null و `comment_column_will_be_added_on_import` برابر true است. نام ستون‌ها را قبل از اشتراک بررسی کنید. مقدار null نامعلوم است. آمار کل شامل آرای قبلی نیز هست؛ خروجی تابع عمومی حداکثر ۱۰ نظر است و لزوماً نمایش واقعی مرورگر نیست.
- نگاشت پزشک/امتیاز/وضعیت پل و پروفایل باید همخوان و جدول InnoDB باشد. در صورت نیاز به فیلدهای اجباری شناخته‌شده با نوع سازگار، مقدار نمونه برای source/reason، شناسه کاربر صفر، hash مصنوعی و تاریخ‌های شناخته‌شده تنظیم می‌شود. فیلد اجباری ناشناخته یا خطا مانع درج است. بعد از DDL، عملیات batch در تراکنش انجام می‌شود؛ قطع ارتباط، triggerها یا عدم دسترسی ALTER ممکن است نتیجه را نامعلوم کند. قبل از تکرار، گزارش بررسی شود.
- حذف/ویرایش نظر، مدیریت رأی، واردات برای پزشک بدون نشان نمونه، نوبت و شمارنده در ابزار نیست. استفاده آتی برای نظرات غیرآزمایشی نیازمند طراحی مستقل است.

تست‌ها در `tests` مخرب و مختص DB کاملاً دورریختنی CI هستند؛ بسته نصب فقط فایل اجرایی دارد. موفقیت آزمایش‌ها لزوماً انطباق با محدودیت‌ها و همه افزونه‌های سایت زنده را تضمین نمی‌کند.
