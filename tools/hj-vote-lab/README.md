# HJ Vote Lab ۰٫۱٫۰ — ابزار آزمایش رأی و خروجی گزارش

ابزار مستقل برای درج **نظرهای مشخصاً آزمایشی** فقط روی پروفایل‌هایی که متای `_hj_demo_doctor` دارند و دریافت فایل JSON تجمیعی همان پروفایل. قبل از استفاده پشتیبان قابل‌بازیابی فایل و DB تهیه کنید. نصب و اجرای آن با مدیر سایت است. این ابزار عمداً به افزونه اصلی، قالب یا تنظیمات دائمی نصب متصل نیست و جدول ایجاد نمی‌کند؛ اما درج نظر روی **جدول واقعی رأی** اثر دارد، ممکن است در صفحه عمومی/امتیاز/رتبه‌بندی دیده شود و با غیرفعال‌کردن افزونه پاک نمی‌شود. متن هر رکورد با برچسب آزمایشی یکتا مشخص می‌شود. دیگر hookها، triggers و کش‌ها ممکن است اثر جداگانه داشته باشند. هیچ دستور حذف داده، پاکسازی یا عملیات خودکار هنگام فعال‌سازی وجود ندارد.

- پیشخوان ← ابزارها ← آزمایش رأی نمونه؛ پروفایل دارای نشان نمونه را انتخاب کنید. ۱ تا ۱۰ خط به شکل `5 | متن` یا CSV کوچک UTF-8 با دو ستون `rating,comment` (header اختیاری) وارد کنید. فایل انتخاب‌شده جایگزین متن کادر است. امتیاز ارقام فارسی و انگلیسی مجاز است.
- وضعیت پیش‌فرض «در انتظار تأیید» است. انتخاب «تأییدشده» ممکن است نظرها را در سایت عمومی و آمار منتشر کند. طبق منطق فعلی پل، آستانهٔ نمایش ستاره و کش می‌تواند باعث شود آمار فوراً به صورت عمومی دیده نشود. افزونه کش را پاک یا متاها را بازنویسی نمی‌کند.
- کنار نام همان جراح «دانلود گزارش» را بزنید؛ خروجی شامل metadata و آمار تجمیعی کل آرای آن جراح نمونه، محاسبه پل و تعداد نظرهای قابل بازخوانی پروفایل است. متن نظرات، IP، شناسه رأی‌دهندگان و نام پزشک در فایل خروجی نیست. مقدار نامعلوم با null نمایش داده می‌شود. گزارش وضعیت غیرتأیید را لزوماً pending نمی‌داند، NULL ممکن است در شمار پل حذف شود و رندر واقعی/کش ممکن است متفاوت باشد. پیش از ارسال JSON نام ستون‌ها و سایر اطلاعات را بررسی کنید.
- درج محدود به جدول پیش‌فرض پروفایل با نگاشت یکسان پل و پروفایل، ستون متن/وضعیت قابل‌تشخیص و موتور InnoDB است؛ ستون اجباری ناشناخته، ناسازگاری یا خطا باعث توقف می‌شود. تراکنش batch شکست عادی INSERT را بازمی‌گرداند و شناسه batch با قفل MariaDB از تکرار ساده پیشگیری می‌کند؛ قطع اتصال هنگام COMMIT یا اثر دیگر افزونه‌ها/triggerها می‌تواند نتیجه را نامعلوم کند. در این حالت پیش از تکرار، گزارش و بکاپ بررسی شوند.
- حذف/ویرایش نظر، مدیریت رأی، واردات روی پزشکان واقعی، نوبت و شمارنده‌ها در این ابزار نیست. استفاده بعدی برای واردات نظرات غیرآزمایشی نیاز به طراحی و بررسی جداگانه دارد؛ این نسخه همان نظرها را صراحتاً آزمایشی برچسب می‌زند.

آزمون‌ها در `tests` مخرب‌اند و فقط در دیتابیس کاملاً دورریختنی GitHub Actions مجازند، نه روی سایت یا کپی واقعی. بسته نصب نباید این تست‌ها را داشته باشد. نتیجه CI مربوط به نسخه نهایی جداگانه بررسی شود.
