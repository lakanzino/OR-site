قالب فرزند اختصاصی سایت آموزشی اتاق عمل بر پایه‌ی قالب والد Lax Theme.

== Description ==

این قالب فقط ویژگی‌های اختصاصی پروژه را نگه می‌دارد: انواع محتوای راهنمای بیمار،
اتاق عمل/تیم/تجهیزات، جراحی‌ها، محتوای دانشجویی و واژه‌نامه، به‌همراه تاکسونومی‌های
آن‌ها. ارائه‌ی عمومی و قالب‌های پایه از والد `lax-theme` به ارث می‌رسند.

متن‌های پزشکی توسط این قالب ساخته نمی‌شوند؛ محتوا را تیم محتوا می‌نویسد و بازبینی می‌کند.

== Installation ==

1. مطمئن شوید قالب والد `lax-theme` نسخه‌ی 1.0.1 نصب است.
2. این قالب را نصب و فعال کنید.
3. یک بار وارد پیشخوان شوید تا دسته‌ها ساخته و پیوندهای یکتا تازه‌سازی شوند.
