# ریسپانسیو سراسری سایت + کارت‌های سه‌تایی — نسخهٔ ۰٫۳٫۵

تاریخ: ۳ نوامبر ۲۰۲۶ · افزونهٔ `hamyar-doctors` `0.3.5` · قالب فرزند `lax-theme-child` `0.33.7`

---

## ۱) مشکل گزارش‌شده

اسکرین‌شات `hamyarjarahi.ir/my-profile/` در عرض موبایل نشان می‌داد فرم پروفایل مثل نسخهٔ دسکتاپ، پهن و بیرون‌زده رندر می‌شود؛ صفحه افقی سرریز می‌کرد و کاربر باید برای دیدن هر فیلد، صفحه را جابه‌جا می‌کرد.

## ۲) ریشهٔ واقعی مشکل

سه علت هم‌زمان، و همه در CSS — نه در مارک‌آپ:

| # | علت | چرا سرریز می‌داد |
| --- | --- | --- |
| ۱ | `.hj-dash__grid { grid-template-columns: 1fr }` در `@media (max-width:900px)` | ستون `1fr` **کف `min-content`** دارد و کوچک‌تر از پهن‌ترین فرزند نمی‌شود. کافی است یک ردیف، پهن باشد تا کل صفحه پهن شود. |
| ۲ | `.hj-dash__hrow { grid-template-columns: 64px auto 1fr auto 1fr }` (پنج ستون) | `input[type="time"]` در مرورگرهای موبایل عرض ذاتی حدود ۱۰۰ پیکسل دارد؛ ۶۴ + «تعطیل» + دو ورودی + «تا» + فاصله‌ها ≈ ۳۸۰ پیکسل در ویوپورت ۳۶۰ پیکسلی. |
| ۳ | کف `min-content` روی شبکه‌های تودرتو | `.hj-dash__pair` و ستون کناری هم همان کف را به والد تحمیل می‌کردند. |

`<meta name="viewport">` در `themes/lax-theme/header.php` درست است؛ پس مشکل «نبودن متا» نبود.

## ۳) چه چیزی ساخته شد

### الف) یک شیت سراسری برای همهٔ سایت

`assets/css/responsive.css` (قالب) = `assets/css/site-responsive.css` (افزونه) — **دو نسخهٔ بایت‌به‌بایت یکسان**:

```
sha256 02203d5c583b8627fb83eb933667abd807bfd7237ae128bcac73c45716492b59
```

پوشش:

- پایه: `-webkit-text-size-adjust`، `overflow-x` کنترل‌شده، `max-width:100%` روی تصویر/ویدیو/iframe/جدول، شکستن رشته‌های بلند (`overflow-wrap:anywhere`).
- `min-width:0` روی `.site-content`، `.site-main`، `.entry-content`، `.wp-block-group` و فرزندان — تا هیچ شبکه‌ای کف `min-content` به صفحه تحمیل نکند.
- جدول‌ها: اسکرول افقی داخلی در موبایل (نه سرریز صفحه).
- فرم‌ها: فونت ۱۶ پیکسل (جلوگیری از زوم خودکار iOS)، هدف لمسی ۴۴ پیکسل.
- سربرگ/ناوبری/پابرگ، مقالات و بلوک‌های وردپرس (`wp-block-columns`، گالری، نقل‌قول، `alignleft/right`)، ابزارک‌ها، صفحه‌بندی، دیدگاه‌ها، نوارهای افقی.
- بخش‌های اختصاصی: صفحهٔ نخست، پروفایل پزشک، راهنمای جراحی، داشبورد و آرشیو پزشکان.

### ب) داشبورد `/my-profile/`

- `minmax(0,1fr)` جای `1fr` در همهٔ شبکه‌ها.
- `≤640px`: ردیف ساعات کاری از پنج ستون به «نام روز + تعطیل» در یک خط و دو بازهٔ زمانی در خط بعد؛ ورودی‌های `type="time"` تمام‌عرض.
- `≤640px`: بلوک عکس، دکمه‌ها و کادر مدارک `wrap` می‌شوند؛ شبب/عنوان با `overflow-wrap:anywhere`.
- همان قواعد هم در `assets/css/dashboard.css` افزونه نوشته شد، پس داشبورد **حتی بدون قالب تازه** هم ریسپانسیو است.

### ج) کارت‌های سه‌تایی صفحهٔ نخست

- `repeat(3, minmax(0,1fr))` در **همهٔ** عرض‌ها؛ بازنویسی‌های دوستونی (`max-width:1050px`) و تک‌ستونی (`780/800/768px`) از `static-home.css` حذف شد.
- مقیاس کوچک‌شونده با `clamp()`: پدینگ کارت از ۳۰ به ۱۲ پیکسل، عنوان از ۱۸ به ۱۳، متن از ۱۴ به ۱۱، آیکون از ۴۸ به ۳۲ — سه کارت در ۳۶۰ پیکسل هم کنار هم می‌مانند.
- **کل کادر کلیک‌پذیر شد** (بدون تغییر مارک‌آپ، پس محتوای ذخیره‌شدهٔ صفحهٔ نخست نیاز به بازدرج ندارد):

```css
.hj-landing-card { position: relative; }
.hj-landing-card > .hj-card-link a::after { content: ""; position: absolute; inset: 0; border-radius: inherit; z-index: 2; }
```

### د) مسیر نصب: فقط افزونه

شیت سراسری از داخل **افزونه** و با آخرین اولویت صف (`wp_enqueue_scripts`, `999`) بارگذاری می‌شود:

- روی سایت فعلی (قالب ۰٫۳۰٫۱ + افزونه) کافی است **ZIP ۰٫۳٫۵ افزونه** نصب شود؛ همهٔ اصلاح‌های موبایل و کارت‌ها می‌نشیند.
- اگر بعداً قالب ۰٫۳۳٫۷ هم نصب شود، همان شیت با handle `lax-theme-responsive` بار می‌شود و افزونه دوباره بارگذاری نمی‌کند (بدون CSS تکراری).

## ۴) آزمون‌ها

| آزمون | نتیجه |
| --- | --- |
| پارس PHP افزونه (`token_get_all` با `TOKEN_PARSE`، PHP 8.4.1) | **۲۶ فایل / ۰ خطا** (فایل تازهٔ `includes/responsive.php` هم شامل) |
| پارس PHP قالب فرزند | **۶۴ فایل / ۰ خطا** |
| پارس CSS (`tinycss2`) روی `responsive.css`، `site-responsive.css`، `static-home.css`، `dashboard.css` | **۰ خطای نگارشی**، آکولادها متوازن |
| آزمون رفتاری صف استایل (۱۴ سنجه) | **۱۴ / ۱۴ PASS** — ثبت در اولویت ۹۹۹، بارگذاری وقتی قالب نسخه ندارد، سکوت وقتی قالب دارد، مسیر/نسخهٔ درست، سه‌ستونی بودن شبکه در پایه و در `768px`، نبود بازنویسی تک‌ستونی، وجود قاعدهٔ لینک کشیده با `inset:0`، ردیف دوستونی ساعات کاری، یکسانی دو نسخهٔ CSS |
| گشایش صفحهٔ نخست در ۳۶۰ پیکسل (محاسبه) | سه کارت × ~۱۰۴ پیکسل + دو فاصلهٔ ۸ پیکسلی = ۳۲۸ < ۳۳۶ پیکسل فضای مفید |

محدودیت صادقانه: در این محیط مرورگر یا PHP نصب‌شده نیست (PHP از طریق `php-wasm` اجرا می‌شود) و اسکرین‌شات خودکار امکان‌پذیر نشد؛ به‌جای آن پیش‌نمایش HTML با **CSS واقعی** ساخته شد: `preview-responsive/index.html` (کارت‌ها در ۳۶۰/۴۱۴/۷۶۸/۱۲۰۰ و داشبورد در ۳۶۰/۴۱۴/۷۶۸). اسکریپت بازبینی ایستای `tools/hamyar-php-review/analyze.php` در این پاس اجرا **نشد** (خطای محیط اجرا)، ولی همهٔ فایل‌های PHP پارس شده‌اند و تنها فایل تازه یک فایل کوچک با نگهبان `function_exists` است.

## ۵) بازگشت

- حذف/تغییر نام `includes/responsive.php` → شیت سراسری افزونه بار نمی‌شود (بقیهٔ افزونه دست‌نخورده).
- در قالب: حذف `assets/css/responsive.css` → تابع `lax_theme_child_responsive_assets` بی‌صدا برمی‌گردد (`file_exists`).
- حذف `assets/css/site-responsive.css` → افزونه بی‌صدا برمی‌گردد (`is_readable`).
