# صفحهٔ پروفایل پزشک — نسخهٔ ۰٫۳٫۳

- **تاریخ:** ۲ نوامبر ۲۰۲۶
- **فایل طراحی:** نمونهٔ HTML تأییدشدهٔ «دکتر داریوش نظری»
- **پیاده‌سازی:** `plugins/hamyar-doctors/includes/profile-page.php` + `assets/css/profile-page.css` + `assets/js/profile-page.js`

## اصل کار

نمونهٔ HTML یک صفحهٔ کامل و ایستا بود (هدر و فوتر اختصاصی، داده‌های نمونه، لینک‌های `#`). نسخهٔ سایت:

۱. **هدر و فوتر سایت حفظ می‌شود.** به‌جای سربرگ و فوتر نمونه، `get_header()`/`get_footer()` قالب اجرا می‌شود و نوار لنگرهای خود صفحه (معرفی، خدمات، سوابق، نظرات، تماس + دکمهٔ نوبت‌گیری) به‌صورت چسبان زیر آن می‌آید.
۲. **هیچ داده‌ای ساختگی نیست.** نام، تخصص، معرفی، شمارهٔ نظام پزشکی، سابقه، خدمات، سوابق تحصیلی، تلفن‌ها، نشانی، ساعات کاری، عکس و امتیاز از پروندهٔ همان پزشک خوانده می‌شوند. فیلد خالی → پیام «ثبت نشده»، نه متن جعلی. نظرات نمونه و ساعات نمونهٔ طرح حذف شدند.
۳. **استایل محدود شده است.** همهٔ قواعد زیر کلاس `.hj-doc` هستند تا با استایل قالب تداخل نکنند و فونت محلی سایت (وزیرمتن) استفاده شود؛ درخواستی به گوگل‌فونت زده نمی‌شود.

## نقشهٔ اتصال لینک‌ها

| جزء طرح | در سایت |
| --- | --- |
| دکمهٔ «نوبت‌گیری» سربرگ، هیرو، کارت ساعات و نوار موبایل | `hj_booking_url` پزشک (VIP)؛ اگر خالی باشد لنگر `#hj-appointment` |
| تلفن مطب / موبایل | `tel:` با ارقام پاک‌شده از `phone_clinic` و `phone_mobile` |
| «مسیریابی» | `map_link` ثبت‌شده؛ اگر نباشد جست‌وجوی گوگل روی «نام پزشک + نشانی مطب» |
| لنگرهای معرفی/خدمات/سوابق/نظرات/تماس | `#hj-about`، `#hj-services`، `#hj-education`، `#hj-reviews`، `#hj-contact` |
| «همهٔ پزشکان» (لینک تازه) | آرشیو نوع محتوای `doctor` |
| ستاره‌های امتیاز | میانگین واقعی از فیلتر `hj_doctor_rating_stats` |
| کارت خدمات | خطوط فیلد `surgeries_performed` (تا ۸ کارت) |
| سوابق تحصیلی | خطوط فیلد `education` |
| ساعات کاری | فیلد تکرارشوی `working_hours`؛ اگر خالی باشد هفت روز با «ثبت نشده» |
| فرم پایین صفحه | `admin-post.php` با اکشن `hj_profile_lead` و nonce |

## فرم

- nonce: `hj_profile_lead_action`، فیلد تلهٔ ربات، checkbox رضایت اجباری، محدودیت نرخ ۶ درخواست در ساعت بر پایهٔ IP.
- پاک‌سازی: `sanitize_text_field`، `sanitize_textarea_field`، `absint` و محدودیت طول؛ نوع درخواست از فهرست مجاز.
- ذخیره: دیدگاه **در انتظار تأیید** روی همان نوشتهٔ پزشک + متاهای `hj_profile_request_type`، `hj_profile_rating`، `hj_profile_phone`.
- پس از تأیید مدیر، نظر در همان بخش «نظرات بیماران» دیده می‌شود؛ درخواست‌های تماس/سؤال برای مدیر ایمیل هم می‌شوند (`hj_profile_lead_notify_email`).
- IP خام ذخیره نمی‌شود؛ فقط برای محدودیت نرخ به‌صورت هش استفاده می‌شود.

## اولویت قالب

پیش‌تر قالب پوسته برندهٔ انتخاب قالب بود و به‌روزرسانی افزونه صفحه را عوض نمی‌کرد. از ۰٫۳٫۳ قالب افزونه اولویت دارد تا با همان به‌روزرسانی، طراحی روی سایت فعال شود. برای بازگشت به قالب پوسته:

```php
add_filter( 'hj_doctors_use_theme_doctor_template', '__return_true' );
```

فایل `themes/lax-theme-child/single-doctor.php` هم به همین رندرکننده وصل شد تا اگر روزی آن فیلتر فعال شود، همان طراحی نمایش داده شود.
