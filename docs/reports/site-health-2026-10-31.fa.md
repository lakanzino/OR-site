3. **سقف آپلود / دسترسی نوشتن / حافظه** — منتفی به‌شکل بالا.

## ۳. تفاوت محیط آزمون با سایت

- دروازهٔ محلی روی **PHP 8.5.10** (ساخت Playground) اجرا می‌شود؛ ۸.۴.۲۷ سایت با `HJ_PHP_VERSION=8.4` درخواست شد ولی Playground ساخت ۸.۴ ندارد و به ۸.۵.۱۰ برگشت. یعنی «PHP ۸.۴ دقیقاً آزموده شد» ادعای درستی نیست؛ آنچه آزموده شده PHP ۸.x با هستهٔ ۷.۱.۴ است.
- آزمون محلی SQLite دارد، سایت MariaDB. کوئری‌های افزونه فقط از API وردپرس استفاده می‌کنند و SQL دست‌نویس ندارند.
