# نوارهای پاستیلی صفحهٔ نخست، پابرگ موبایل و تیتر زیر تصویر شاخص — نسخهٔ ۰٫۳٫۶

تاریخ: ۳ نوامبر ۲۰۲۶ · افزونهٔ `hamyar-doctors` `0.3.6` · قالب فرزند `lax-theme-child` `0.33.8`

---

## ۱) سه خواسته

1. ستون‌های سه‌تایی صفحهٔ نخست به **نوارهای باریک** با **سایهٔ عمیق دورتادور** و **رنگ پاستیلی** تبدیل شوند؛ روی نوار فقط **تیتر اصلی** بماند و متن ریز راهنما حذف شود.
2. پابرگ در موبایل **دوستونه**، فونت ریزتر، فاصله‌های نزدیک‌تر و جمع‌وجورتر.
3. تیتر زیر تصویر شاخص **در هر حالتی کامل جا بیفتد** (با تغییر اندازهٔ فونت)، نه بریده‌شده با سه‌نقطه.

## ۲) چه چیزی تغییر کرد

### الف) کارت‌های صفحهٔ نخست (`responsive.css` بخش ۷)

| ویژگی | قبل | بعد |
| --- | --- | --- |
| عرض کارت | پرکردن ستون (`1fr`) | نوار باریک با `max-width: 210px` و `justify-items: center` |
| پس‌زمینه | سفید | پاستیلی: نعنایی `#e6f5ee` · یاسی `#eee9fb` · هلویی `#ffece1` |
| سایه | یک لایهٔ ملایم پایین | دو لایهٔ عمیق دورتادور + خط نور داخلی: `0 18px 34px -10px rgba(24,60,55,.34)`, `0 8px 16px rgba(24,60,55,.14)`, `inset 0 1px 0 rgba(255,255,255,.75)` |
| ارتفاع | خودکار | `min-height: clamp(170px, 21vw, 270px)` تا نوارها هم‌قد شوند |
| متن | آیکون + تیتر + توضیح + لینک ریز | **فقط آیکون + تیتر**؛ `p:not(.hj-card-icon):not(.hj-card-link){display:none}` |
| کلیک‌پذیری | لینک ریز پایین کادر | همان لینک، با متن `font-size:0` و `::after{inset:0}` روی **کل نوار** |
| چیدمان | سه‌ستونی | سه‌ستونی در **همهٔ** عرض‌ها (بدون تغییر) |

آیکون روی زمینهٔ پاستیلی سفید شد تا خوانا بماند و سایهٔ نرم گرفت.

### ب) پابرگ موبایل (`responsive.css` بخش ۶)

- `.hj-footer__top` در `≤768px` به **دو ستون مساوی** تبدیل شد و بلوک برند با `grid-column: 1 / -1` تمام عرض را گرفت (لوگو + شعار + ایمیل بالا، دو ستون لینک زیرش کنار هم).
- علت اصلی بلندی و پراکندگی پابرگ پیدا شد: قاعدهٔ سراسری «هدف لمسی» `.site-footer a{min-height:44px}` بود که هر لینک پابرگ را ۴۴ پیکسل بلند می‌کرد. حالا ۴۴ پیکسل فقط برای **سربرگ و ناوبری** است و لینک‌های پابرگ `min-height:0` با پدینگ ۱ پیکسلی دارند.
- فونت‌ها کوچک‌تر: شعار و ایمیل `0.74rem`، تیتر ستون‌ها `0.78rem`، لینک‌ها `0.74rem` با `line-height: 1.5`، فاصلهٔ آیتم‌ها `0.28rem`، نوار پایانی `0.7rem` و وسط‌چین.
- لوگو در پابرگ موبایل حداکثر ۳۴ پیکسل ارتفاع دارد.

### ج) تیتر زیر تصویر شاخص (`responsive.css` بخش ۱۶)

علت بریده‌شدن، `.orsite-card-article__title a{white-space:nowrap; overflow:hidden; text-overflow:ellipsis}` در `child.css` بود. حالا:

```css
.orsite-card-article__title,
.orsite-card-article__title a {
	white-space: normal; overflow: visible; text-overflow: clip; overflow-wrap: anywhere;
}
.orsite-card-article__title { font-size: clamp(.82rem, .78rem + .3vw, 1.05rem); line-height: 1.7; }
```

یعنی تیتر در چند خط کامل می‌شکند و اندازهٔ فونت با عرض صفحه سیال است؛ هیچ سه‌نقطه‌ای باقی نمی‌ماند.

## ۳) ترتیب بارگذاری (مهم)

`static-home.css` روی اولویت **۱۰۰** صف می‌شود؛ شیت سراسری قالب از ۹۹ به **۹۹۸** رفت تا همیشه بعد از آن بنشیند. نسخهٔ پشتیبان افزونه روی **۹۹۹** است؛ ترتیب اجرا: ۹۸ → ۱۰۰ → ۹۹۸ (قالب) → ۹۹۹ (افزونه، که وقتی قالب شیت را دارد ساکت می‌ماند).

## ۴) آزمون‌ها

| آزمون | نتیجه |
| --- | --- |
| پارس PHP افزونه / قالب (PHP 8.4.1) | **۲۶/۰** و **۶۴/۰** |
| پارس CSS (`tinycss2`) روی چهار شیت | ۰ خطا، آکولادها متوازن |
| آزمون رفتاری صف استایل | **۲۳/۲۳ PASS** (شامل: نوار ۲۱۰px، سایهٔ دو‌لایه، پس‌زمینهٔ پاستیلی، حذف متن راهنما، لینک کشیده، پابرگ دوستونه، `grid-column:1/-1` برند، فونت ۰٫۷۴، حذف `min-height:44px` از پابرگ، `white-space:normal` و نبود `nowrap`/`line-clamp` روی تیتر کارت، و نگهبان‌های رگرسیون داشبورد) |
| یکسانی دو نسخهٔ CSS قالب/افزونه | `sha1` برابر |

پیش‌نمایش‌ها (CSS واقعی، مارک‌آپ واقعی): `preview-responsive/index.html` — کارت‌ها در ۳۶۰/۴۱۴/۷۶۸/۱۱۸۰، پابرگ در ۳۶۰/۴۱۴/۱۱۸۰، کارت‌های مقاله در ۳۶۰/۷۶۸.

محدودیت: در این محیط مرورگر نصب نیست، پس اسکرین‌شات خودکار گرفته نشد.

## ۵) بازگشت

- کارت‌ها: حذف بخش ۷ از `responsive.css` (و `site-responsive.css`) ظاهر قبلی را برمی‌گرداند؛ محتوای صفحه دست‌نخورده است.
- پابرگ: حذف بلوک `@media (max-width: 768px)` بخش ۶.
- تیتر مقاله: حذف بخش ۱۶؛ قاعدهٔ `nowrap` در `child.css` دست‌نخورده مانده و خودش برمی‌گردد.
