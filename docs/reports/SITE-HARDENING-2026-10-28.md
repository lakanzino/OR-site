## ۲. آنچه در این نسخه ساخته شد

### ۲-۱. دروازهٔ انتشار (`inc/publish-gate.php`)

| بررسی | سطح | آستانه (فیلترپذیر) |
|---|---|---|
| حجم متن | بازدارنده | ≥ ۹۰۰ کلمه (`hj_gate_min_words`) |
| منابع بیرونی | بازدارنده | ≥ ۲ لینک (`hj_gate_min_sources`) |
| بخش هشدار + اشاره به ۱۱۵ | بازدارنده | H2/H3 «تماس/اورژانس/هشدار» + ۱۱۵ |
| تصویر شاخص + Alt | بازدارنده | Alt ≥ ۲۰ نویسه |
| عدد ممنوع (mg/cc/درصد موفقیت/دوز) | بازدارنده | الگوهای صریح |
| لینک داخلی | هشدار | ≥ ۲ |
| پرسش‌های متداول | هشدار | ≥ ۳ در متا یا بخش متن |
| جدول دورهٔ بهبود (مقالهٔ «بعد از عمل») | هشدار | ≥ ۱ جدول |
| دسته‌بندی محتوا | هشدار | ≥ ۱ اصطلاح |

- فقط **انتشار تازه** را می‌بندد؛ ویرایش مقالهٔ زنده هرگز آن را به پیش‌نویس برنمی‌گرداند.
- مدیر سایت با تیک «انتشار با وجود خطا» می‌تواند عبور کند؛ بقیه نقش‌ها نه.
- باکس کنارِ ویرایشگر همیشه وضعیت را نشان می‌دهد (✔ / ! / ✖) تا نویسنده پیش از زدن «انتشار» بداند چه کم است.

## ۳. آنچه آگاهانه انجام نشد

1. **نصب افزونهٔ جدید:** هیچ افزونه‌ای اضافه نشد؛ تعداد افزونه‌ها همان است و همهٔ قاعده‌ها در قالب ماند.
2. **بازگرداندن بایلاین پزشک:** رد شد (ADR-020). اگر روزی صاحب سایت بخواهد، باید ADR تازه بنویسد، نه اینکه کد قدیمی برگردد.
3. **تولید خودکار متن یا Alt:** خلاف منشور محتوایی (C1/C2) و ریسک YMYL.
4. **راه‌اندازی کش سرور:** تصمیم هاست، نه مخزن.
