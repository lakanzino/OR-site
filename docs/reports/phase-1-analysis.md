## ۳. معماری و هوک‌ها (`functions.php` و `inc/`)
- `sarzaminaryan_setup()` روی `after_setup_theme`: ترجمه، title-tag، thumbnails، custom-logo (‏240×80 انعطاف‌پذیر)، HTML5، responsive-embeds، align-wide، wp-block-styles، editor-styles، دو منو (primary/footer)
- سایز تصویر: hero ‏1200×675 + کارت `sarzaminaryan-card` ‏600×338
- `$content_width = 1200` ✅
- دارایی‌ها: fonts ← main (با `rtl: append`) ← style.css؛ اسکریپت با `strategy: defer`؛ preload فقط Vazirmatn-Regular؛ `comment-reply` فقط هنگام نیاز ✅
- Customizer: بخش `sarzaminaryan_options` + تنظیم `sarzaminaryan_footer_text` (در قالب قبلی استفاده نمی‌شد، در 1.1.0 اصلاح شده) ✅
- Template tags: متای تاریخ/نویسنده و فوتر نوشته با escaping کامل

## ۴. یافته‌های مثبت (حفظ شوند)
1. بدون jQuery، بدون CDN و بدون درخواست خارجی؛ فونت کاملاً محلی (OFL)
2. CSS با ویژگی‌های منطقی (logical properties) — RTL/LTR بدون هک دوبرابر (main-rtl.css فقط ۲ قانون)
3. دسترس‌پذیری: skip-link استاندارد، `.screen-reader-text` صحیح، ‏`:focus-visible` واضح، اهداف لمسی ۴۴px، ‏`prefers-reduced-motion`، بستن منو/جستجو با Escape و مدیریت فوکوس
4. کنتراست اندازه‌گیری‌شده روی سفید: متن ‏14.76، ‏primary ‏(#0e7490) ‏5.36، ‏primary-dark ‏7.27، ‏muted ‏5.80 — همه ≥ ‏WCAG AA برای متن عادی (4.5)
5. امنیت: هیچ `$_GET/$_POST` مستقیمی نیست؛ خروجی‌ها `esc_html/esc_url/esc_attr` شده‌اند؛ گارد `ABSPATH` در فایل‌های اصلی
6. عملکرد: lazy برای تصاویر کارت، eager+fetchpriority برای hero، ‏aspect-ratio ‏16/9 (ضد CLS)

## ۷. مشکلات باز و ریسک‌ها
- تبدیل به Block Theme (فازهای ۲–۳ نقشه‌راه) بزرگ‌ترین کار باز است و نباید با تغییر نام اشتباه گرفته شود.

- پس از تغییر نام، قالب فرزند قبلی (`sarzaminaryan-child`) دیگر به این والد وصل نمی‌شود (Template name عوض شده) — Breaking Change آگاهانه (ADR-002).
