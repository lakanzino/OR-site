# گزارش گام C5 — حذف کامل سبز و پالت تک‌رنگ سرمه‌ای (فرزند 0.4.0)

> **قانون اول (همیشه): هر فایلی که برای صاحب سایت فرستاده می‌شود، فقط با لینک قابل دانلود از گیت‌هاب یا گوگل درایو ارائه می‌شود. مسیر محلی یا فایل بی‌لینک ارسال نمی‌شود.**


- **دستور کارفرما:** «رنگ سبز رو کامل با آبی Navi تغییر بده و هایلایت هم از خود آبی تیره استفاده کن»
- **نسخه:** `lax-theme-child` از 0.3.0 به **0.4.0** رسید؛ قالب والد 1.0.1 بدون تغییر ماند.

## تغییرات

- متغیرهای `--bx-green`، `--bx-green-bright` و `--bx-green-light` حذف شدند؛ جایگزین‌ها: `--bx-highlight: #06265C`، `--bx-highlight-deep: #041A3F` و `--bx-navy-mid: #0A2F6B`.
- `--color-accent` و `--color-link-hover` هم سرمه‌ای شدند.
- هایلایت‌ها (قبلاً سبز روشن با نوشته‌ی تیره) حالا باکس سرمه‌ای تیره با نوشته‌ی سفیدند:
  - خلاصه‌ی مقاله (`.orsite-article__lead`)
  - توضیح تصویر (`figcaption` و `.orsite-caption`؛ کلاس `--dark` برای سازگاری قبلی نگه داشته شد)
  - نقل‌قول، باکس سلب مسئولیت (نوار کناری سفید برای تفکیک روی زمینه‌ی سرمه‌ای) و ستون متن الگوهای تصویر (`.orsite-media__text`)
- اکسنت‌های جزئی: نوار بالای باکس تیتر، برچسب‌ها (قرص سرمه‌ای با نوشته‌ی سفید، هاور معکوس سفید)، آیتم فعال منو، تیتر H3، هاور عنوان کارت و لینک‌های فهرست مطالب، دکمه‌ی جستجو/ارسال، حلقه‌ی فوکوس، نقطه‌ی فهرست تیک‌دار، رنگ انتخاب متن و گرادیان‌های برند/هیرو/کارت — همه سرمه‌ای.
- پیش‌نمایش `design/boxed-design-preview.html` هم با همین پالت بازسازی شد.

## دروازه‌ی تست

- `php -l` همه‌ی فایل‌های فرزند سبز (فقط CSS/نسخه‌ها عوض شدند).
- گِرِپ روی CSS سرو شده: هیچ کد رنگ سبزی (`#0B6E4F`، `#12B981`، `#DCF5E8` یا `rgba(18,185,129…)`) وجود ندارد.
- وردپرس واقعی: `/`، ‏`/surgery/`، ‏`/surgery/appendectomy-test/` و `/patient-guide/` همگی HTTP 200؛ `child.css?ver=0.4.0` لود می‌شود؛ باکس تیتر، خلاصه و کپشن در خروجی حاضر؛ `debug.log` بدون خطای جدید.
