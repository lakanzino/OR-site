## ۳. سبک نگارش (از مقالات واقعی)

### ۳.۱. راوی

- **نام:** محمدرضا لک (تکنسین اتاق عمل، ۱ سال سابقه)
- **در مقالات:** فقط خط byline ساده — `محمدرضا لک` (نه بیوگرافی کامل)
- **در درباره ما:** نام + سمت + تجربه کامل
- **در برگه‌های حقوقی:** `تحریریهٔ همیار جراحی`

### ۳.۲. ویژگی‌های سبک (از مقاله `operating-room-moment-by-moment`)

1. **اول‌شخص با تجربهٔ واقعی:** "سال‌ها در اتاق عمل کنار بیمارانی بوده‌ام..."
2. **خاطره واقعی:** یه خاطره از یه شیفت شبانه با پدر یه بیمار — نه کلیشه، نه ساختگی
3. **همدلی:** "ترس اون پدر از خودِ عمل نبود؛ از تصویری بود که از اتاق عمل توی ذهنش ساخته بود"
4. **جزئیات حسی:** دما، نور، بو، صدا — همه رو توصیف می‌کنه
5. **لحن احتمالی:** "معمولاً"، "ممکن است"، "طبق دستور پزشک"
6. **بدون عدد قطعی:** هیچ ساعت ناشتایی، دوز یا درصدی نمی‌ده
7. **باورهای نادرست:** یه بخش مخصوص برای رفع misconceptions
8. **جدول خلاصه:** در انتهای هر مقاله
9. **FAQ با ۳-۵ سؤال**
10. **علائم هشدار + ۱۱۵**
11. **منابع** با لینک مستقیم
12. **سلب مسئولیت** — فقط یک جمله

### ۳.۳. مثال از لحن واقعی

```
"در این لحظه، ممکن است احساس کنید وارد فضایی شده‌اید که برای شما ساخته نشده 
و برای تیمی ساخته شده که سال‌ها در آن کار کرده است. این احساس طبیعی است. 
اما بدانید این فضا برای همین کار طراحی شده: انجام یک عمل ایمن و کنترل‌شده."
```

```
"بعضی‌ها می‌گویند طعم فلزی یا بوی خاصی حس کردند. بعضی‌ها هم چیز خاصی حس نکردند.
لحظه از دست دادن هوشیاری برای هر کس متفاوت است."
```
