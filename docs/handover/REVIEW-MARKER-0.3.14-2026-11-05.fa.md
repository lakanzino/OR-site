# نمایش برچسب نظر نمونه — همیار پزشک‌ها ۰٫۳٫۱۴

## زمینه و دامنه

پس از تأیید کارفرما برای ادامه، شناسه طولانی batch افزونه Vote Lab در تصویر عمومی مشاهده شده بود. در `plugins/hamyar-doctors/includes/profile-render.php` فقط متن خروجی reader عمومی برای جراح دارای متای `_hj_demo_doctor` و پیشوند دقیق UUIDv4 افزونه Vote Lab از `[نظر آزمایشی HJ-…] متن` به `[نظر آزمایشی] متن` تبدیل می‌شود. متن ذخیره‌شده، شناسه batch، وضعیت، ستاره، شمار و میانگین در DB تغییر نمی‌کنند. این reader هم برای رندر پروفایل و هم AJAX نظرات استفاده می‌شود. نظر عادی، الگوی ناقص، شناسه در وسط متن و جراح بدون نشان تغییر نمی‌کنند. افزونه Vote Manager همان متن ذخیره‌شده را می‌بیند و شناسه حفظ می‌شود.

نسخه افزونه اصلی به ۰٫۳٫۱۴ افزایش یافت. این بسته علاوه بر تغییر بالا، کار ثبت‌شده نسخه ۰٫۳٫۱۳ روی شاخه را شامل می‌شود: گزارش metadata اضافی ساختار رأی برای مدیر؛ ۰٫۳٫۱۳ جداگانه روی سایت نصب نشده بود. قالب و افزونه‌های مستقل تغییر نکرده‌اند. `releases/hamyar-doctors-0.3.14.zip` فقط فایل‌های runtime دارد، نه fixture یا tests. SHA-256: `efc944b6c8dc29f0b39eb534eb861f46721b8c2433153f0ebf43eef027c1d8b3`.

## آزمون

بسته با فایل‌های runtime منبع byte-by-byte مقایسه شد. اجرای CI شماره `41949271325` در commit `acc69ae742db6c4ae308b52d435f63c8d849d387` هر شش job را با موفقیت گذراند. تست‌های WordPress 7.1.4/PHP 8.4/MariaDB 11.4 روی DB دورریختنی شامل reader، رندر HTML و escaping، AJAX عمومی و nonce، متن عادی، marker ناقص یا میانی، جراح بدون نشان، نظر pending و مقایسه ردیف‌های DB پیش و پس اجرا هستند. آزمون ارتقای مصنوعی با version-option قدیمی و صفحه نخست مصنوعی نیز در fixture اضافه شد؛ جایگزین آزمون واقعی جایگزینی فایل در همه پیکربندی‌ها نیست. هیچ عملیات زنده‌ای توسط ایجنت صورت نگرفته است.

## نصب و بازگشت

پس از بکاپ، ZIP افزونه اصلی را با روش نصب/جایگزینی افزونه موجود وردپرس نصب کنید، نه به‌عنوان افزونه دوم؛ سپس کش سایت و مرورگر را پاک و پروفایل همان جراح نمونه را ببینید. اگر پیشوند استاندارد و نشان نمونه برقرار باشند، برچسب «نظر آزمایشی» باقی می‌ماند اما UUID عمومی دیده نمی‌شود. در صورت ناسازگاری یا خطا، بازگردانی فایل افزونه قبلی معتبر ۰٫۳٫۱۲ و بکاپ مطابق رویه سایت لازم است؛ پاک‌کردن کش ممکن است لازم شود. بازگشت افزونه به‌تنهایی جدول یا ردیفی را حذف نمی‌کند. این نسخه اصلاح نمایش است، نه حذف فیزیکی یا تکمیل مدیریت رأی، نوبت‌دهی و شمارنده‌ها. PR #106 باز است و انتشار/نصب زنده تأیید نشده است.
