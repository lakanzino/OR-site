# 05 — پشتیبان‌گیری و Google Drive

======================================================================



## بکاپ هفتهٔ‌ای (UpdraftPlus یا Backuply)

- زمان‌بندی: **هفتگی**، شب/ساعت کم‌ترافیک. فایل‌ها + دیتابیس.

- نگهداری: حداقل ۴ نسخه.

- مقصد: **بیرون از سرور** (Drive خصوصی/S3/…).

- حتماً شامل `wp-content/uploads/` (و در نتیجه `hj-private/`).

- ⚠️ بکاپ‌ها مدارک پزشکان را هم دارند؛ مقصد را خصوصی نگه دار، لینک عمومی نساز، دسترسی را محدود کن.

- قبل از هر به‌روزرسانی مهم افزونه/قالب/هسته: بکاپ دستی.

- **یک بار تست بازیابی** (ترجیحاً روی staging) انجام بده؛ بکاپ تست‌نشده را بکاپ حساب نکن.



## پوشهٔ Google Drive: `lax-Dr-profile`

ساختار پیشنهادی:

```

lax-Dr-profile/

├─ docs/ (فصل‌های ۰۰ تا ۱۰ همین سند)

├─ releases/ (ZIP افزونه و قالب فرزند، با تاریخ/نسخه)

├─ data/ (CSV/JSON استان‌ها و شهرستان‌ها؛ نسخهٔ اصلی sarzaminaryan)

├─ acf-json/ (کپی دو فایل JSON)

├─ status-reports/ (اسکرین‌شات صفحه‌های وضعیت بعد از نصب)

└─ backups-index/ (فقط فهرست: تاریخ، حجم، محل نگهداری)

```

قوانین:

- «Anyone with the link» **خاموش**؛ فقط اشخاص مشخص.

- **قرار نده:** Client Secret گوگل، رمزها، مدارک واقعی پزشکان، فایل بکاپ دیتابیس.

- اگر نسخهٔ جدیدی نصب شد، ZIP قبلی را در releases/ نگه دار تا بازگشت ممکن باشد.
