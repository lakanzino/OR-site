# مدیریت رأی نمونه ۰٫۱٫۰ — گزارش برای بررسی مشاور

## وضعیت و دامنه

کارفرما پس از مشاهده دو نظر آزمایشی خواست خطای CSV فعلاً کنار گذاشته شود و مرحله بعد ادامه یابد. افزونه مستقل `tools/hj-vote-manager/hj-vote-manager.php` مدیریت رأی جراحان دارای `_hj_demo_doctor` را با اختیار `manage_options` و POST/nonce فراهم می‌کند؛ نه افزونه اصلی و نه قالب را تغییر نمی‌دهد. این نسخه حذف فیزیکی، مدیریت جراحان بدون نشان، خروجی گزارش و اصلاح نمایش عمومی شناسه آزمایشی ندارد. فهرست انتخاب حداکثر ۱۰۰ جراح نمونه و صفحات رأی هر کدام ۵۰ ردیف است. تاریخچه صفحه ۳۰ تغییر آخر همان جراح را نشان می‌دهد.

## ایمنی و تغییرات DB

نگاشت پل و خواننده بررسی، شناسه PK تکی و status متنی، نوع ستون‌ها و موتور InnoDB لازم است. HMAC وضعیت قبلی و SELECT FOR UPDATE به تشخیص فرم کهنه کمک می‌کنند؛ قفل مشورتی مشترک با Lab استفاده می‌شود. با اولین تلاش معتبر برای ذخیره، جدول گزارش اختصاصی با پیشوند وردپرس ساخته می‌شود (DDL مستقل و دائمی). ذخیره رأی و رویداد شامل مدیر، زمان UTC، مقادیر قبلی/جدید، متن و دلیل در یک تراکنش است. در خطای ثبت گزارش rollback درخواست می‌شود. تغییر خودکار اتصال یا نتیجه نامعلوم commit نیازمند بررسی دستی است؛ قطع اتصال واقعی و رقابت چنداتصالی به‌طور کامل آزموده نشده‌اند. جدول گزارش حاوی متن نظر و محرمانه است. توقف افزونه داده‌ها را بازنمی‌گرداند.
