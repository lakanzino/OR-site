# مرحلهٔ گزارش مدیر — قالب ۰٫۳۳٫۱۸ و افزونه ۰٫۳٫۱۰

کارفرما اعلام کرد قالب ۰٫۳۳٫۱۷ در سایت متصل است، محتوای مخزن مطابق سایت است و خواست نسخه بالاتر رود و اجرای تغییرات به‌تدریج ادامه یابد. این اعلام را مبنای کار می‌گیریم؛ کد مخزن به‌تنهایی وجود/مقدار optionها، داده‌ها و پیکربندی واقعی را نشان نمی‌دهد. این مرحله فقط گزارش کمینه و مجزای مدیر است، نه تغییر ناوبر، رأی، ثبت‌نام یا محتوای صفحهٔ نخست.

## تغییرات

- افزونهٔ ۰٫۳٫۱۰: `includes/admin-data-status.php` صفحهٔ مستقل «پزشک‌ها ← وضعیت داده‌ها» با capability `manage_options`، پذیرش GET، no-cache، بدون فرم یا لینک عملیاتی. ردیف‌ها تعداد پنج وضعیت پزشک و تعداد تمام پست‌های doctor دارای متای `_hj_demo_doctor`، وضعیت ثبت سه option، اتصال هر سه تابع به `admin_init` در زمان گزارش، نسخه و تعداد چهار taxonomy را نشان می‌دهند. هیچ نام، شناسه، اطلاعات شخصی یا جدول رأی نمایش داده نمی‌شود.
- گزارش در صورت خطای DB برای شمارش‌ها «نامعلوم» نشان می‌دهد؛ count ترم‌ها تعداد پزشکان نیست، وضعیت‌های دیگر در ردیف‌های پنج‌گانه نیستند، شمار علامت‌دار همه وضعیت‌ها را پوشش می‌دهد؛ نشانگر بودن یا نبودن اثبات ماهیت واقعی نیست. has_action فقط قلاب مذکور را نشان می‌دهد، نه همه راه‌ها. گزارش خود نوشتنی انجام نمی‌دهد، اما WP یا افزونه‌های دیگر در همان درخواست ممکن است بنویسند.
- قالب ۰٫۳۳٫۱۸: فقط شماره و سوابق نسخه برای انتشار با افزونه به‌روز شده‌اند؛ طرح بصری تازه ندارد. گزارش مخصوص مدیر است نه ابزار ویرایش رأی. محدودیت‌های و هشدارهای ۰٫۳۳٫۱۷ برای قالب و ارتقای افزونه همچنان برقرارند.

## آزمون

- WordPress 6.8.3 / PHP 8.3 / SQLite دورریختنی: دسترسی ناشناس، مشترک و پزشک رد شد؛ POST مدیر رد شد؛ اولویت صفر برای قلاب به‌درستی شناسایی شد؛ وجود شمارش وضعیت و نشانگر و escaping و نبود فرم/عنوان خصوصی/لینک عملیات بررسی شد؛ state انتخاب‌شده قبل و بعد رندر ثابت بود و خطای DB نامعلوم نمایش داده شد. منوی مستقل ثبت شد؛ مسیر واقعی پیشخوان برای مدیر ۲۰۰ و مشترک ۴۰۳ برگرداند، هدر no-cache مشاهده شد. این آزمون کل تغییرات و همه نقش‌ها یا افزونه‌های خارجی را پوشش نمی‌دهد.
- PHP 8.3 WASM فایل‌های PHP تغییرکرده را پارس کرد؛ تست قلاب‌های سیدر و بسته‌بندی افزونه و ۹ تست نسخه/ZIP قالب موفق بودند. ZIPهای جدید حاوی tests نیستند. آزمون MySQL، محیط واقعی، درستی محتوای دیتابیس و مرورگرهای واقعی انجام نشده است.
