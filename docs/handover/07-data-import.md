# 07 — ورود داده

======================================================================

مسیر: ابزارها → «ورود داده‌ها (همیار)»



## گرفتن فایل

1. از کاربر فایل استان/شهرستان sarzaminaryan.ir را بخواه (CSV یا JSON). نسخهٔ اصلی را در `lax-Dr-profile/data/` ذخیره کن.

2. Excel بود: Save As → CSV UTF-8. (کدگذاری Windows-1256 و UTF-16 هم خودکار خوانده می‌شود.)



## ستون‌های CSV

| ستون | الزامی | توضیح |

|---|---|---|

| province | بله | نام استان (پیشوند «استان » نادیده گرفته می‌شود) |

| province_slug | خیر | اسلاگ؛ پیشنهاد لاتین (مثل tehran) |

| province_en | خیر | نام انگلیسی |

| city | خیر | نام شهرستان؛ اگر خالی فقط استان ساخته می‌شود |

| city_slug | خیر | اسلاگ شهرستان؛ تکراری خودکار پسوند می‌گیرد |

| city_en | خیر | نام انگلیسی |

- هر سطر = یک شهرستان؛ نام استان در هر سطر تکرار شود.

- جداکننده: , یا ; یا Tab (خودکار).

- عنوان ستون فارسی هم مجاز: استان، شهرستان، اسلاگ_استان، …

- JSON: آرایهٔ سطرها، ساختار تودرتو `[{"name":"تهران","cities":[...]}]` یا نقشهٔ `{"تهران":[...]}`.

- اگر دو جدول جدا (استان‌ها و شهرها با province_id) بود: در Google Sheets با VLOOKUP نام استان را کنار هر شهر بیاور.

- اگر عنوان ستون شناخته نشد، خطا ستون‌های خوانده‌شده را نشان می‌دهد؛ سه خط اول فایل را بفرست.



## روش

پیش‌نمایش (پیش‌فرض روشن) → کنترل اعداد (۳۱ و ۴۸۳) → برداشتن تیک → اجرا → hj_seed_status.

ایدمپوتنت است: اجرای دوباره امن. رابطهٔ شهرستان←استان با term meta `hj_province_id` است (نه والد-فرزند بومی؛ تصمیم معماری تأییدشده).
