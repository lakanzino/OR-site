# 03 — چک‌لیست تست نهایی

======================================================================

علامت بزن: ✅ موفق / ❌ ناموفق (با توضیح و اسکرین‌شات). تست‌های مهمان در Incognito.



## A) سلامت کلی

- [ ] سایت و پیشخوان بدون خطا باز می‌شوند؛ debug.log خالی از Fatal است.

- [ ] هر ۱۱ صفحهٔ وضعیت بدون خطای سفید باز می‌شود.

- [ ] همهٔ URLهای موجود (فصل ۰۰) ۲۰۰ می‌دهند و محتوایشان مثل قبل است.

- [ ] symptom-checker هنوز غیرفعال است و تغییری نکرده.



## B) پروفایل پزشک (/doctor/dr-demo-*/ و /doctor/114/)

- [ ] فیلدهای خالی کاملاً مخفی‌اند (هیچ برچسب خالی).

- [ ] نام/تخصص/بیوی فارسی بزرگ و انگلیسی کوچک و جدا؛ هیچ ترجمهٔ خودکاری نیست.

- [ ] ارقام: فارسی در بخش فارسی، لاتین در بخش انگلیسی.

- [ ] RTL کامل؛ بلوک انگلیسی LTR موقت.

- [ ] ساعات کاری درست (روز تعطیل، ساعت‌ها).

- [ ] پزشک پیش‌نویس/مخفی برای مهمان **۴۰۴** می‌دهد.

- [ ] view-source: ساختار JSON-LD فقط فیلدهای پر؛ `aggregateRating` فقط با ≥۵ رأی تأییدشده.

- [ ] قوانین امتیازدهی هیچ‌جا در UI نمایش داده نمی‌شوند.

- [ ] متن قوانین امتیازدهی در /privacy/ و /terms/ توسط صاحب محتوا نوشته شده (ایجنت فقط وجودش را چک کند).



## C) آرشیو و جست‌وجو

- [ ] /doctor/ فقط پزشکان عمومی را نشان می‌دهد (۱۲ مورد در هر صفحه).

- [ ] فیلتر ترکیبی تخصص + استان + شهرستان با AND کار می‌کند.

- [ ] جست‌وجو: «ارتوپدی»، بخشی از نام، نام استان/شهر، املای عربی (ي/ك) نتیجه می‌دهد.

- [ ] مرتب‌سازی «بیشترین امتیاز» کار می‌کند.

- [ ] /specialty/<x>/ و /province/<x>/ و /city/<x>/ باز می‌شوند.

- [ ] منوی هدر `lax-theme` سالم است و فرم جست‌وجوی پزشک تداخلی ندارد.

- [ ] (فقط اگر FacetWP روشن است) فیلترها بدون رفرش کار می‌کنند.



## D) فونت و تم (بخش ۱۳)

- [ ] در Network مرورگر: Vazirmatn و Inter با وضعیت ۲۰۰ و نوع font/woff2.

- [ ] در /doctor/، یک پروفایل، /my-profile/: `hj-scope` در body هست؛ در /about/ و صفحهٔ اصلی **نیست**.

- [ ] پالت: navy `#061A2E`، teal `#14C8C0`؛ بدون قرمز/زرد بی‌دلیل.

- [ ] در فرم /my-profile/ فیلد الزامی خالی → پیام inline زیر فیلد (بدون حباب مرورگر، بدون alert).

- [ ] hj_theme_status: اسکن `alert(`/`confirm(`/`prompt(` در JS افزونه خالی است (اگر نبود، فایل dashboard.js را برای اصلاح بفرست).

- [ ] دارک‌مود: `?hj_theme=dark` روی پروفایل، داشبورد، آرشیو درست دیده می‌شود؛ بعد از تأیید، HJ_DARK_MODE='auto' و تست با Chrome DevTools → Rendering → Emulate prefers-color-scheme.

- [ ] حالت روشن بعد از دارک‌مود دچار پسرفت نشده.



## E) ثبت‌نام و ورود پزشک

- [ ] از Incognito: `/?hj_google_start=1` → ورود گوگل → ریدایرکت به /my-profile/.

- [ ] کاربر جدید نقش `doctor` گرفت (hj_auth_status).

- [ ] ورود عادی گوگل بدون «intent» نقش پزشک نمی‌دهد (مثلاً خریدار/خواننده).

- [ ] کاربر فقط‌پزشک به /wp-admin/ نمی‌رسد (ریدایرکت به /my-profile/) و نوار مدیریت ندارد.



## F) داشبورد پزشک

- [ ] ساخت پروفایل → ذخیرهٔ فیلدها → آپلود عکس (JPG/PNG/WebP، حداکثر ۲MB) → ارسال برای بررسی.

- [ ] فایل با پسوند جعلی (مثلاً exe تغییرنام‌داده به jpg) **رد** می‌شود.

- [ ] وضعیت: پیش‌نویس → در انتظار → منتشر/رد؛ مدیر از ستون وضعیت در لیست پزشکان تأیید می‌کند.

- [ ] کارت امتیاز فقط‌خواندنی است.

- [ ] یک پزشک نمی‌تواند پروفایل پزشک دیگر را ویرایش کند (`?hj_edit=` فقط برای مدیر).

- [ ] داشبورد مینیمال و بدون شلوغی؛ بدون popup.



## G) مدارک خصوصی (حیاتی)

- [ ] یک **مدرک آزمایشی** (نه واقعی) آپلود کن.

- [ ] آدرس مستقیم فایل در `uploads/hj-private/p<ID>/…` را در Incognito باز کن: باید ۴۰۳/۴۰۴ شود.

- [ ] دانلود از داخل داشبورد (با nonce) کار می‌کند.



## H) امتیازدهی

- [ ] مهمان رأی می‌دهد → در جدول با وضعیت «در انتظار» ثبت می‌شود (hj_rb_status).

- [ ] رأی دوم از همان IP برای همان پزشک رد می‌شود.

- [ ] میانگین فقط با ≥۵ رأی تأییدشده نمایش داده می‌شود.

- [ ] متاباکس مدیر در ویرایش پزشک: تعدیل دستی/امتیاز پنهان کادر درمان کار می‌کند و **هرگز** به‌صورت رأی جدا دیده نمی‌شود.

- [ ] رکوردهای قدیمی `hj_doctor_votes` بدون تغییر ماندند (تعداد قبل/بعد را مقایسه کن).



## I) REST و ویجت

- [ ] `/wp-json/hj/v1/doctors` و `/wp-json/hj/v1/doctor/<id>`: فقط پزشکان عمومی؛ کلیدهای مجاز: id,url,name,specialty,specialties,province,city,photo,rating.

- [ ] هیچ‌جا: شمارهٔ نظام/تلفن/ایمیل/آدرس/امتیاز داخلی/delta (hj_rest_status self-test).

- [ ] پزشک مخفی/پیش‌نویس ۴۰۴.

- [ ] `/?hj_widget=114` در یک iframe روی صفحهٔ HTML تست (در سایت دیگر یا فایل محلی) لود می‌شود.

- [ ] جعبهٔ embed در پروفایل: کد iframe/script ساخته می‌شود و دکمهٔ کپی کار می‌کند.



## J) ریسپانسیو (DevTools → Responsive)

- [ ] <۵۲۰px موبایل؛ ۵۲۰–۹۰۰ تبلت؛ >۹۰۰ دو ستون.

- [ ] کارت: width:100%، بدون سرریز افقی.



## K) داده

- [ ] ۳۱ استان و ۴۸۳ شهرستان؛ شهرستان‌های هم‌نام اسلاگ یکتا دارند؛ دوباره‌ایمپورت چیزی تکراری نمی‌سازد.

- [ ] پزشک بدون عکس: تصویر اتاق عمل (یا SVG) دیده می‌شود، نه عکس شکسته.



## L) نوبت‌دهی (باید خاموش باشد)

- [ ] hj_hooks_status: «خاموش (پیش‌فرض)»؛ همهٔ تست‌های خودکار موفق.

- [ ] در view-source پروفایل، `hj-appt-slot` وجود ندارد؛ هیچ جدول `hj_appt_` ساخته نشده.



## M) کش و بکاپ

- [ ] /my-profile/ و querystringهای hj_* ، fwp_* ، hj_theme کش نمی‌شوند (دو بار باز کن؛ نباید HTML قدیمی/اشتراکی ببینی).

- [ ] یک بکاپ زمان‌بندی‌شدهٔ هفتگی اجرا شد و فایل آن در مقصد بیرونی هست.
