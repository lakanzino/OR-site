# فازبندی پروفایل پزشکان متخصص — دستور ۱ نوامبر ۲۰۲۶ صاحب سایت

**نسخه:** ۱.۰ · **وضعیت:** مصوب صاحب سایت · **مجری:** سردبیر مجلهٔ اینترنتی همیار جراحی

> اصل کلی: بخش پروفایل پزشکان **متخصص در هر رشته** ساخته می‌شود؛ همهٔ پروفایل‌ها دسته‌بندی‌شده و مجزا. فقط جراحان/متخصصان (حوزهٔ امتیازدهی همان «جراحان» است).

---

## ۱. فاز ۱ — متخصصان معروف (رایگان)

- با **متخصصان معروف هر رشته** شروع می‌کنیم: پروفایلشان رایگان ساخته و به وب‌سایت متصل می‌شود.
- فهرست معروف‌های هر رشته را صاحب سایت تأمین می‌کند (یا سردبیر پیشنهاد و صاحب سایت تأیید می‌کند).
- داده‌های پروفایل از منابع عمومی/رسمی (سازمان نظام پزشکی، سایت مطب/بیمارستان) — بدون ادعای «تأییدشده توسط سایت».

## ۲. فاز ۲ — پزشکان و جراحان درجه دو (فقط با پرداخت هزینه)

- ساخت پروفایل پزشکان و جراحان درجه دو **فقط در ازای پرداخت هزینه** انجام می‌شود.
- مبلغ و روش پرداخت: [تصمیم صاحب سایت].
- روند: درخواست + پرداخت ← تأیید وصول توسط سردبیر ← ساخت پروفایل (همان ساختار فاز ۱) ← انتشار.
- **قاعدهٔ بی‌طرفی (الزامی برای جلوگیری از شکایت):** پرداخت فقط بابت *ساخت و درج پروفایل* است؛ هیچ تأثیری در ترتیب نمایش، میانگین ستاره، نشان «پیشنهادی» یا جست‌وجو ندارد. این دقیقاً بند ۳ سیاست نسخهٔ ۱.۱ و تصمیم ۷ پژوهش (BGH VI ZR ۳۰/۱۷) است: اگر پول با رتبه مخلوط شود، حق اعتراض/حذف پروفایل برای پزشکان ایجاد می‌شود.

## ۳. کارت پروفایل (مستطیل کوچک) — فیلدها همه مجزا و دسته‌بندی

هر پروفایل یک کارت مستطیل کوچک دارد با این فیلدها، هر کدام در خط جدا:

۱. **نام** (دکتر …)
۲. **مدرک تحصیلی** (تخصص/فوق تخصص)
۳. **کد نظام پزشکی**
۴. **محل طبابت** (شهر/منطقه + نشانی)
۵. **خلاصهٔ کوتاه سوابق** (۲ تا ۳ خط)

به‌علاوه: **دستهٔ رشته** (تخصص) و بلوک ستاره‌ای (قالب موجود `single-doctor.php` بدون تغییر).

### نشانه‌گذاری کارت (داخل فیلد محتوای پست `doctor` paste شود)

```html
<div class="doctor-card">
  <p class="dc-name"><strong>نام:</strong> دکتر …</p>
  <p class="dc-degree"><strong>مدرک تحصیلی:</strong> …</p>
  <p class="dc-code"><strong>کد نظام پزشکی:</strong> …</p>
  <p class="dc-location"><strong>محل طبابت:</strong> …</p>
  <p class="dc-bio"><strong>خلاصهٔ سوابق:</strong> …</p>
</div>
```

### CSS پیشنهادی (یک‌بار در Customizer → CSS اضافی)

```css
.doctor-card{max-width:420px;border:1px solid #e3e6ea;border-radius:10px;padding:12px 16px;background:#fafbfc;margin:8px 0 16px}
.doctor-card p{margin:4px 0;font-size:.95rem}
```

## ۴. دسته‌بندی رشته‌ها (صفحهٔ مجزا برای هر تخصص)

- در **Custom Post Type UI** یک taxonomy به نام `specialty` روی پست‌تایپ `doctor` بسازید (Has Archive = true).
- برای هر رشته یک ترم: مثلاً جراحی عمومی، ارتوپدی، چشم، زیبایی، زنان، مغز و اعصاب، گوش و حلق و بینی، قلب، اورولوژی…
- نتیجه: آدرس‌های مجزا مثل `/specialty/orthopedics/` با فهرست پزشکان همان رشته — «همه به‌صورت دسته‌بندی و مجزا».
- در منوی سایت: «پزشکان» ← زیرمنوی رشته‌ها.

## ۵. مراحل اجرا (هر پزشک)

۱. ساخت پست `doctor` (عنوان = نام پزشک) + انتخاب دستهٔ `specialty`.
۲. Paste کردن کارت پروفایل در محتوا + تصویر شاخص.
۳. ثبت آرای اولیه طبق [`seed-votes.fa.md`](seed-votes.fa.md) (تعداد و توزیع رندوم).
۴. انتشار؛ بررسی نمایش ستاره‌ها در صفحهٔ تکی.
۵. ثبت در دفترچهٔ داخلی سردبیر: نام، رشته، فاز (رایگان/پولی)، تاریخ، تعداد آرای اولیه.

## ۶. اتصال به وب‌سایت

- لینک پروفایل‌ها از صفحهٔ فهرست پزشکان/رشته‌ها و منوی اصلی.
- قالب صفحهٔ تکی همان `themes/lax-theme-child/single-doctor.php` است (بلوک ستاره + فرم رأی).
- صفحه‌های سیاست (نسخهٔ ۱.۱) در فوتر همهٔ صفحات — از جمله پروفایل‌ها — لینک باشند.
