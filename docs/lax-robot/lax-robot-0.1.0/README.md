## در یک نگاه

«ربات معاینه بیمار لکس» ابزاری فارسی و راست‌به‌چپ برای بیمار است: چند پرسش دربارهٔ درد شکم می‌پرسد، نشانه‌هایی که کاربر گزارش کرده را به موضوع‌های بالینی **مستند** وصل می‌کند و می‌گوید «این نشانه‌ها با این موضوع‌ها هم‌خوان است» — نه تشخیص، نه درصد، نه امتیاز. پاسخ‌ها **هیچ‌جا ذخیره یا فرستاده نمی‌شوند**.

## وضعیت واقعی امروز

- **آزموده و سبز:** ۱۲۹ آزمون موتور و رابط، ۱۷ آزمون ابزار نویسندگی، ۲۲ آزمون مهاجرت، ۲۲ آزمون بسته، ۶۵ آزمون بازرسی، ۱۲ سناریوی دود رابط، عکس طلایی ۲۵ سناریو + ۵۰۰۰ مسیر، و چهار کار CI (از جمله WordPress ۶.۸.۳ و ۷.۱.۴ در Playground).
- **نصب‌شده روی سایت زنده:** افزونهٔ `0.1.3` (آخرین نصب تأییدشده). نسخه‌های `0.1.4` تا `0.1.7` **نصب نشده‌اند** و در مرورگر واقعی دیده نشده‌اند.
- **آزموده‌نشده:** رفتار با کاربر واقعی (هیچ پاسخ واقعی ثبت و بازبینی نشده)، و انتخاب پرسش تطبیقی (فاز ۴ شروع نشده).
- **مرز اعلام‌شده:** این ابزار تشخیص نمی‌دهد، نمی‌سنجد، ذخیره نمی‌کند و جای پزشک را نمی‌گیرد. هر متن تازه `pending_team_review` است تا تیم تأیید کند.
