# ابزار: symptom-checker-ui — نسخهٔ 0.1.7

**پوشه = نام ابزار = نسخه.** مسیر سورس: `symptom-checker/ui/` · همراه افزونهٔ `0.1.7` منتشر می‌شود.

## چه می‌کند

همان چیزی را که موتور گفته نشان می‌دهد: کارت موضوع، هشدار ایمنی مستقل، «اطلاعات کافی نیست»، شواهد گروه‌بندی‌شده، بازگشت/ویرایش پاسخ و شروع دوباره. فارسی و راست‌به‌چپ.

## فایل‌ها و مسئولیت

| فایل | مسئولیت |
| --- | --- |
| `app.js` | چرخهٔ پرسش/پاسخ، رندر، دو `fetch` محلی (بسته و نقشهٔ شاهد) |
| `view-model.js` | تبدیل `result()` به مدل نمایش؛ برابری با موتور |
| `question-help.js` | متن راهنمای هر پرسش و **هر گزینه** (یک جمله برای هر گزینه) |
| `styles.css` | ظاهر؛ آبی پس‌زمینه، نارنجی پررنگ، متن درشت (خوانایی مرز است) |

## قاعده‌های محتوا

- هر پرسش و هر گزینه خط راهنما دارد؛ خط «نمی‌دانم» برچسب واقعی همان گزینه را می‌آورد.
- ممنوع: درصد، امتیاز، «قطعاً»، «احتمال ابتلا». آزمون همین را می‌گیرد.
- متن آزاد زیر «نمی‌دانم» **فقط ثبت و نمایش** می‌شود؛ روی مسیر، شاهد یا نتیجه اثر صفر.

## چه چیزی را **نه**

- ذخیره‌سازی (localStorage/کوکی/سرور)، ارسال به بیرون، تحلیل رفتار.
- نمایش `profile_match`.
- هر کنترلی برای پرچم استراتژی (فقط کانفیگ).

## آزمون

`node --test symptom-checker/ui/tests/*.test.js` (از جمله `question-help.test.js` که **هر دو** بستهٔ v1 و v2 را می‌بیند) · `ui-smoke.mjs --all` (۱۲ سناریو؛ نیازمند jsdom).
