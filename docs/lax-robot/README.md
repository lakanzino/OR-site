# ربات معاینه بیمار لکس — دفتر توسعه

این پوشه، **سند نسخه‌دار** توسعهٔ «ربات معاینه بیمار لکس» است: چه ساخته شد، چرا، با چه شاهدهایی، و امروز دقیقاً در چه وضعی است. جای [چنج‌لاگ](../PROJECT-CHANGELOG.md) را نمی‌گیرد؛ آن یکی رویدادها را فهرست می‌کند، این یکی **معماری و روند ساخت** را توضیح می‌دهد.

## قاعدهٔ نام‌گذاری

نام ابزار = نام پوشه = نسخه:

```text
docs/lax-robot/
├── README.md                     ← همین فایل (فهرست و قاعده)
└── lax-robot-0.1.0/              ← نسخهٔ ۰.۱.۰ سند
    ├── README.md                 ← وضعیت و فهرست همان نسخه
    ├── architecture.fa.md        ← معماری آن‌چنان‌که ساخته شده
    ├── development-log.fa.md     ← روند ساخت، فاز به فاز، با شاهد
    ├── MANIFEST.json             ← فهرست فایل‌ها و sha256
    └── tools/
        ├── symptom-checker-engine-0.1.7/
        ├── symptom-checker-ui-0.1.7/
        └── symptom-checker-author-0.1.0/
```

## چطور یک ابزار تازه اضافه می‌شود

1. پوشهٔ تازه در `tools/` با نام `<نام-ابزار>-<نسخه>` بسازید؛ نام پوشه = نام ابزار = نسخه. هیچ فایلی جابه‌جا نمی‌شود.
2. یک `README.md` در آن بگذارید که بگوید ابزار چه می‌کند، ورودی/خروجی‌اش چیست، چه چیزی را تضمین می‌کند و چه چیزی را **نه**.
3. در `architecture.fa.md` فقط مرزهایش را اضافه کنید (به چه چیزی وابسته است، چه چیزی را لمس نمی‌کند).
4. نسخهٔ بالادستی سند (`lax-robot-<نسخه>`) را بالا ببرید؛ نسخهٔ قبلی **پاک نمی‌شود**، مثل بسته‌های افزونه.
