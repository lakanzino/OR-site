# مرحلهٔ ۵.۱۶ — بازبینی با مرورگر و HTTP وردپرس دورریختنی

**فقط CI، روی loopback و دادهٔ ساختگی؛ نه endpoint افزونه، قابلیت قابل نصب یا مجوز استقرار.** این گام رابط مرحلهٔ ۵.۱۵ را از طریق یک router صرفاً آزمایشی به همان توابع intent و MariaDB دورریختنی وصل می‌کند. کتابخانهٔ مشترک آزمایشی از fixture قبلی جدا شده تا رفتار مقایسه تکرار نشود؛ تست‌های سابق همچنان اجرا می‌شوند.

برای مرورگر، ورود با cookie و رمز ساختگی وردپرس، توانایی و مالکیت `hj_booking_can_configure`، nonce وابسته به کاربر/نشست و پزشک، POST JSON، منع cache و تفکیک actor بررسی می‌شوند. صفحه کلید درخواست را در حافظه نگه می‌دارد، storage نمی‌نویسد و هیچ مسیر ذخیره، لغو یا تأیید نهایی ندارد. هش ردیف‌های intent و snapshot پیش و پس از مرور مقایسه می‌شود. صفحهٔ نخست حداکثر سه ردیف، انتخاب صریح و refresh مستقل وضعیت و revision را حفظ می‌کند.

دو intent هم‌محتوا هر دو تطبیق می‌کنند؛ تطبیق هویت قطعی نیست. پاسخ `different` یا فهرست خالی نیز اثبات عدم commit نیست. مقایسه و خواندن وضعیت/برنامه یک snapshot اتمیک نیستند. nonce مجوز نیست؛ بررسی دسترسی جداست. برای محصول، طراحی نرخ درخواست و جلوگیری از oracle، retention/restore، چرخهٔ salt، احراز هویت و خطاهای شبکه، سایر writerها و migration جدا لازم‌اند. مرورگر OAuth واقعی، ACF، سایت، شبکهٔ عمومی، قطع حین COMMIT و idempotency محصولی را اثبات نمی‌کند.

نتیجهٔ CI هنوز در انتظار است؛ پیشرفت ۷۵٪ ثابت و هیچ کد افزونه، ZIP یا سایت زنده تغییر نکرده است.
