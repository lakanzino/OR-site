## ۴. ویرایش برگه

برگه ← ویرایش. در ویرایشگر فقط یک خط می‌بینید: `[hamyar_symptom_checker]`.

- می‌توانید بالای آن متن بنویسید (مثلاً توضیح خودتان)؛ ابزار همان‌جا زیرش می‌آید.
- این خط را پاک نکنید؛ اگر پاک شود، ابزار روی آن برگه نمایش داده نمی‌شود.

## ۵. اگر صفحه بالا نیامد

از ۰.۱.۱۴ خود صفحه پیام می‌دهد: «ابزار در این مرورگر بالا نیامد» + نسخه + آدرس فایل رابط + متن خطای مرورگر. همان متن را بفرستید.

علت قبلی (صفحهٔ آبی خالی) این بود که تگ `type="module"` توسط افزونهٔ کش حذف می‌شد؛ حالا تگ مستقیم چاپ می‌شود. اگر باز هم تکرار شد، اول **کش LiteSpeed** را خالی کنید (LiteSpeed Cache ← پاک‌کردن همه).
