## چطور محتوا را بدون ریلیز عوض کنید

```sh
python3 tools/symptom-checker-author/author.py publish-bundle
# → dist/hj-sc/knowledge-bundle.<version>.<sha8>.json
```

1. فایل را در `wp-content/uploads/hj-sc/` بگذارید (بسازید اگر نیست).
2. برگهٔ ابزار را یک بار با حساب مدیر باز کنید یا کش LiteSpeed را پاک کنید.
3. برای برگشت: option `hj_sc_active_bundle` را روی نام فایل قبلی بگذارید، یا فایل تازه را پاک کنید (بازگشت خودکار به بستهٔ داخل زیپ).

**اگر چیزی خراب باشد، صفحه سالم می‌ماند:** فایل گم‌شده، JSON ناسالم، `schema_version` ناخوانا یا بستهٔ بی‌پرسش همه رد می‌شوند و بستهٔ داخل زیپ سرو می‌شود.
