# Hamyar Jarahi — Sentinel (خودپایشگر سلامت محتوا)

افزونهٔ مستقل و سبک که مقاله‌های `surgery` و `patient_guide` را با چک‌لیست YMYL می‌سنجد و نتیجه را در پیشخوان نشان می‌دهد.

## چرا این شکل؟

- **فقط می‌خواند.** نوشتهٔ منتشرشده هیچ‌وقت خودکار تغییر نمی‌کند. دکمهٔ «ساخت پیش‌نویس اصلاح» یک پیش‌نویس جدا با بلوک پیشنهادی می‌سازد؛ انتشار فقط با ذخیرهٔ انسانی.
- **بدون تشخیص پزشک بازبین.** آن ساختار در ADR-020 حذف شده است؛ به‌جایش ساختار، منابع، پرسش‌ها، خلاصهٔ بالینی و تازگی سنجیده می‌شود.
- **بدون ریدایرکت عمومی.** فقط مسیرهای نقشهٔ دستی ۳۰۱ می‌شوند و مسیرهای جابه‌جاشده از `_wp_old_slug` فقط وقتی یکتا باشند.

## چک‌لیست شش‌گانه

| چک | سطح |
|---|---|
| باکس علائم هشدار (`hj-box--danger` / `[hjbox danger]` / ⚠️) | خطا |
| منابع: ۳ دامنه از فهرست سفید + یک منبع ردهٔ ۱ | خطا |
| بخش پرسش‌های متداول (بدنه یا ردیف‌های ویرایشگر) | هشدار |
| خلاصهٔ بالینی (≥۲ ردیف تأییدشده) | هشدار |
| ساختار: ≥۶ H2 و بدون H1 | هشدار |
| تازگی: آخرین ویرایش ≤۴۰۰ روز | هشدار |

## کجا؟

- **کنار ویرایشگر مقاله:** درصد انطباق، موارد باز، دکمهٔ پیش‌نویس اصلاح، ثبت بازبینی انسانی.
- **ابزارها → سنتینل:** جدول همهٔ مقاله‌ها، میانگین، خروجی JSON، ویرایش نقشهٔ ۴۰۴ و فهرست ۴۰۴های ماه.

## هزینه

صفر در فرانت: نه CSS، نه JS. تنها کد عمومی، بررسی ۴۰۴ است که بعد از `is_404()` اجرا می‌شود و یک آپشن می‌خواند.

## نصب

پوشهٔ `hamyar-sentinel-agent` را در `wp-content/plugins/` بگذارید و فعال کنید. برای شمارش منابع، قالب فرزند همیارجراحی باید فعال باشد؛ در غیر این صورت آن چک «هشدار: شمارش انجام نشد» می‌دهد.
