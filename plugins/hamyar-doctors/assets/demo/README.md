# Demo doctor — نمونهٔ پزشک

`demo-doctor.dr-demo-general.json` یک پروفایل نمونه و کاملاً ساختگی است تا شکل پلتفرم پزشکان
(کارت در صفحهٔ اول، آرشیو `/doctors/`، REST `hj/v1`) دیده شود و ایرادات پیدا شود.

## ساخت دستی در پیشخوان (بدون ترمینال)

1. **پزشکان ← افزودن پزشک** → عنوان «دکتر دمو — پزشک عمومی»، اسلاگ `dr-demo-general`، وضعیت «منتشر».
2. زمینه‌های ACF را مطابق JSON پر کنید (نام، تخصص، بیو، ساعات کاری، ...). همه داده‌ها ساختگی باشند.
3. تخصص «پزشکی عمومی»، استان «تهران»، شهر «تهران» را انتخاب کنید (از بخش ۱۴ ایمپورت شده‌اند).
4. بدون تصویرPublished → تصویر پیش‌فرض اتاق عمل/آواتار نمایش داده می‌شود.
5. صفحهٔ اول  و `/doctors/` را باز کنید؛ کارت نمونه باید در بخش «پلتفرم پزشکان و جراحان» صفحهٔ اول دیده شود.
