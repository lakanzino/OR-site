# بررسی‌گر فقط‌خواندنی همگام‌سازی پروفایل

این افزونه مشخصات فایل `inc/disease-directory.php` در **قالب فرزند فعال** را فقط به مدیر سایت نشان می‌دهد تا قبل از پیشنهاد اصلاح، نسخهٔ نصب‌شده با فایل مرجع مخزن سنجیده شود.

- هیچ مقاله یا پروفایل و هیچ فایل قالبی را تغییر نمی‌دهد. تنظیمات فعال‌شدن خود افزونه را وردپرس مثل سایر افزونه‌ها نگه می‌دارد.
- محتوای فایل، اطلاعات بیمار، پاسخ‌های ابزار یا داده‌های نوشته‌ها را به جایی ارسال نمی‌کند. خروجی شامل نام و نسخهٔ قالب، تعداد خطوط شناخته‌شده و هش SHA-256 فایل است.
- فقط کاربر دارای `manage_options` در **ابزارها ← بررسی همگام‌سازی پروفایل** صفحه را می‌بیند.
- `matches_original_tag` یعنی هش فایل دقیقاً با فایل مربوط در تگ `child-v0.30.0` برابر است؛ صرف برابر بودن نسخهٔ قالب ۰٫۳۰٫۰ چنین چیزی را ثابت نمی‌کند.
- `original_line_custom_file` یعنی خط قدیمی پیدا شده اما فایل دقیقاً مثل مرجع نیست؛ نباید با فایل مرجع جایگزین شود.
- `fixed_line_found` یعنی خط اصلاح‌شده مشاهده شده، نه اینکه کل سامانه یا سایر مسیرها بدون خطا هستند.
- `unrecognized_or_ambiguous` و `unreadable` یعنی باید پیش از هر تغییر بررسی شود؛ افزونه هیچ اصلاح خودکاری ندارد.

## روش استفاده

۱. ZIP را در پیشخوان ← افزونه‌ها ← افزودن افزونه ← بارگذاری نصب و فعال کنید.
۲. به **ابزارها ← بررسی همگام‌سازی پروفایل** بروید.
۳. تصویر صفحه را برای بررسی بفرستید. پس از آن می‌توانید افزونه را غیرفعال کنید.

نسخهٔ آزمایشی در WordPress 6.8.3 و PHP 8.2 با فایل تگ واقعی و سناریوهای فایل تغییرکرده، خط اصلاح‌شده، الگوی چندگانه و نبود فایل آزموده شد. محیط واقعی سایت و کارکرد مرورگری آن هنوز آزموده نشده است. این افزونه به‌خودی‌خود مشکل ذخیره را اصلاح نمی‌کند.
