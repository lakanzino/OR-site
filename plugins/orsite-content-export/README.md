# ORSite — خروجی کامل مقاله‌ها

افزونه‌ای سبک برای مدیر سایت که همهٔ نوشته‌های سایت را دانلود می‌کند؛ منتشرشده، پیش‌نویس، در انتظار، خصوصی و زمان‌بندی‌شده.

## نصب
1. فایل `releases/orsite-content-export.zip` را دانلود کنید.
2. در پیشخوان وردپرس: **افزونه‌ها → افزودن → بارگذاری افزونه** را انتخاب کنید، ZIP را بدهید و فعال کنید.
3. از منوی **ابزارها → خروجی مقاله‌ها** وارد شوید.

## خروجی
- **JSON (کامل):** برای هر نوشته عنوان، نامک، لینک، تاریخ انتشار و به‌روزرسانی، نویسنده، چکیده، تعداد کلمه، متن HTML و متن ساده، تصویر شاخص، همهٔ دسته‌ها و برچسب‌ها، و متادیتا (از جمله `_hj_*` قالب).
- **CSV (خلاصه):** فهرست عنوان‌ها و مشخصات اصلی برای Excel (با BOM یونیکد).

## امنیت
- فقط کاربران با دسترسی `manage_options` می‌توانند استفاده کنند.
- هر دانلود با nonce وردپرس محافظت شده است.
- هیچ داده‌ای به سرور دیگری ارسال نمی‌شود؛ فایل مستقیم در مرورگر شما دانلود می‌شود.

## نکته
خروجی شامل پیش‌نویس‌ها هم هست. اگر فقط منتشرشده‌ها لازم است، فیلتر `oce_statuses` را تغییر دهید یا به فایل JSON فیلد `status` را نگاه کنید.
